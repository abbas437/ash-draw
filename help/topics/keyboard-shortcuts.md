## Ctrl keys
| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>O</kbd> / <kbd>S</kbd> | New, Open, Save |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> or <kbd>Ctrl</kbd>+<kbd>F4</kbd> | Close the tab |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous tab |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / Redo |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy / Copy with Base Point |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Paste / Paste as Block |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find and replace |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print |
| <kbd>Ctrl</kbd>+<kbd>3</kbd> | Side panel expanded / collapsed |

While you type in a field, only <kbd>Ctrl</kbd>+<kbd>S</kbd>, <kbd>O</kbd>, <kbd>N</kbd>, <kbd>W</kbd>, <kbd>F</kbd> and <kbd>P</kbd> work.

## Function keys
| Key | Action |
|---|---|
| <kbd>F2</kbd> | Command history (in the Layers list: rename the layer) |
| <kbd>F3</kbd> | Object snap on/off |
| <kbd>F7</kbd> | Grid |
| <kbd>F8</kbd> | Ortho |
| <kbd>F9</kbd> | Snap to grid |
| <kbd>F10</kbd> | Polar tracking |
| <kbd>F11</kbd> | Object snap tracking |
| <kbd>Shift</kbd>+<kbd>F10</kbd> | Menu of the focused tab or tool button |

Ortho and polar tracking switch each other off. See [Drafting aids](#topic:drafting-aids).

## Esc, Enter, Space, Del
- <kbd>Esc</kbd> cancels the current tool or clears the selection; it also closes the command history.
- <kbd>Enter</kbd> finishes the current tool. With no tool running it repeats the last one.
- <kbd>Space</kbd> acts as Enter where a tool accepts it (for example grip modes).
- <kbd>Del</kbd> erases the selection.
- Typing a letter or digit starts a command on the [command line](#topic:command-line) ([Show me](#showme:el:cmd)); <kbd>↑</kbd>/<kbd>↓</kbd> on an empty line recall earlier input.

## Mouse
- **Wheel:** zoom (speed: `ZOOMFACTOR`).
- **Middle-drag** or <kbd>Space</kbd>+drag: pan, in any tool.
- **Double-click** (Select tool): enter a layout viewport or edit a block.
- **Right-click** on the drawing: Enter for most tools.
- **Middle-click** a tab: close it.
