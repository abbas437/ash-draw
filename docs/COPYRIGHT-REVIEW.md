# Copyright, licence and trademark review - ASH Draw Studio

Status: internal engineering review of the release build, 2026-10-07. This is not legal
advice; items needing a professional opinion are listed in the owner checklist at the end.

## 1. The application itself

ASH Draw Studio is original code released under the MIT licence
(`LICENSE`, Copyright (c) 2026 ASH Technical & Project Management Services (ASH PMCS)).
The icon (`build/icon.png`) is the ASH brand icon, the owner's own artwork (see the last section).

## 2. File formats

### DXF
DXF is a published format, free to implement.

### DWG
DWG is Autodesk's format. Reverse-engineered readers are lawful for interoperability. The
USPTO refused Autodesk's attempts to register "DWG" as a trademark (merely descriptive).

Even so, the project uses the term descriptively only:

- We say "DWG file support" and describe DWG as a file format.
- We never use Autodesk, AutoCAD, RealDWG or TrustedDWG branding, logos or names to
  describe or promote the product.
- We never write the TrustedDWG watermark into saved files.
- The README states that the product is not affiliated with or endorsed by Autodesk.

## 3. LibreDWG (GPL-3.0-or-later)

DWG conversion uses GNU LibreDWG 0.14.8597 (libredwg), licensed GPL-3.0-or-later.

- **Unmodified**: `dwg2dxf.exe`, `dxf2dwg.exe`, `libredwg-0.dll` and `libiconv-2.dll` (GNU libiconv, LGPL-2.1-or-later, a separate unmodified DLL used only by libredwg) are taken byte-for-byte
  from the official upstream Windows x64 release archive. `scripts/fetch-libredwg.mjs` refuses
  the archive unless its SHA-256 matches the pinned value.
- **Separate executables, no linking**: the app starts the converters as separate processes
  with `execFile` (no shell) and exchanges data through temporary files. It does not link to,
  load or embed LibreDWG, so the MIT-licensed app and the GPL programs are separate works
  distributed together.
- **Shipped with** `resources/libredwg/COPYING` (GPL text) and
  `resources/libredwg/README-SOURCE.txt` (version, file hashes, source links and a written
  offer).
- **Source**: https://github.com/LibreDWG/libredwg/releases/tag/0.14.8597 and
  https://github.com/LibreDWG/libredwg/releases/download/0.14.8597/libredwg-0.14.8597.tar.xz. The CI workflow downloads and
  hash-verifies `libredwg-0.14.8597.tar.xz` and attaches it to every tagged GitHub Release next to
  the installers.
- It is listed in `THIRD-PARTY-NOTICES.md` as the one deliberate exception to the
  permissive-licence allow-list (which applies to npm packages).

## 4. Components deliberately NOT bundled

- **Open Design Alliance SDK / ODA File Converter**: not bundled. Their terms forbid
  redistribution without membership.
- **Autodesk DWG TrueView**: not bundled.
- **SHX fonts**: Autodesk SHX fonts are Autodesk property and are not bundled. Text is drawn
  with system fonts.

## 5. Data tables

The ACI colour table is a public de-facto table, generated algorithmically.

## 6. npm dependencies

Runtime dependencies are MIT: `pdf-lib`, `@pdf-lib/fontkit` (the DXF reader/writer is our own code, no parser library). `pako` is pulled in
transitively under "MIT AND Zlib". The complete list with licence texts is generated by
`npm run licenses` into `THIRD-PARTY-NOTICES.md`; that script fails the build if a production
dependency has a licence outside the permissive allow-list.

## 7. Electron and Chromium

The runtime is Electron (MIT). Electron embeds Chromium and Node.js; their notices ship with
every build as `LICENSE.electron.txt` and `LICENSES.chromium.html` in the installation folder.

## 8. Product name

The name "ASH Draw Studio" has had no trademark search.

## 9. Code signing

The Windows executables are unsigned. Windows SmartScreen warns on first run; the README tells
users how to verify the SHA-256 published in `SHA256SUMS.txt` before running.
